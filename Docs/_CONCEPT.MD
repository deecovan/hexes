# Концепт игры.

## MMO, PVE, PVP
Открытый мир ММО с героями, которые ходят по карте.
Герои ищут монстров и боссов для победы и дропа карт.
При встрече героя другого игрока:
  - можно вызвать его на дуэль,
  - можно обменяться картами.
У каждого игрока есть город, где живут герои.
Один из героев со своей колодой назначается защитником.
Перцептрон защитника нужно обучать оборонять город.
Когда игрок оффлайн, перцептрон защитника отражает атаки других игроков.
У каждого города с защитником есть рейтинг.
Рейтинг города сбрасывается при изменении защитника (героя или колоды).
Изменение рейтинга нападающего героя и защитника происходит по системе ELO.

## Части игры:
1. Карточная дуэль.
2. Мир, где герои собирают свои колоды. 
  - Монстры, боссы, дроп карт, PVE гринд,
  - PVP и обмен картами.
3. Города, которые атакуют/защищают герои со своими колодами.
  - Перцептрон героя.
  - Обучение перцептрона, игра этим героем и колодой.
  - Атака города, онлайн и оффлайн.
